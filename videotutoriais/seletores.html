Tipos de seletores CSS

Por Ana Gabriela Nobre

1. Seletor universal: *

Todos os elementos desta página têm a letra Arial, por causa do seletor *.

2. Seletor de tipo: h1, h2, section

Todos os h2 são rosa e todas as section são caixas brancas.

3. Seletor de classe: .destaque

Este texto é normal, mas este tem a classe destaque.

Uma classe pode ser usada em vários elementos.

4. Seletor de id: #especial

Este parágrafo tem o id "especial". Um id só pode existir uma vez na página.

5. Seletor de atributo: [target="_blank"]

Link normal Link que abre noutra aba (verde)

6. Pseudo-classes: :hover, :first-child, :nth-child

  • Primeiro item (rosa, :first-child)
  • Segundo item (fundo, :nth-child(even))
  • Terceiro item
  • Quarto item (fundo, :nth-child(even))

7. Pseudo-elementos: ::first-letter, ::before

Tóquio brilha ao anoitecer, mil luzes começam a aparecer.

Este parágrafo tem uma estrela criada pelo CSS.
